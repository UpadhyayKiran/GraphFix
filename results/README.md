# Included Phase-1 Results

This directory contains a compact, reviewable subset of the frozen Phase-1 evidence. No result was recomputed for publication.

| Path | Purpose |
|---|---|
| `phase1_evaluation_summary/` | Full-560 aggregate method comparison and final summary |
| `adaptive_fixed_full560/` | Adaptive Fixed aggregate, per-instance outcomes, and efficiency analysis |
| `pilot_summary/` | Pilot metrics, summary, and navigation-efficiency figures |
| `ablations/` | Candidate-expansion n=20 and n=50 ablation summaries |
| `localization_benchmark/evaluation_cohort.json` | Frozen cohort definition |

Large per-instance result trees, full trace collections, raw issue records, run logs, model caches,
and reconstructed repositories remain in the private academic archive. Their absence is not
evidence of missing evaluation: the included aggregate and per-instance Adaptive outcome files
cover all 560 frozen instances.

See `docs/PHASE1_FINAL_RESULTS.md`, `docs/PHASE1_ADAPTIVE_EVALUATION.md`, and `docs/PHASE1_REPRODUCIBILITY.md` for interpretation and reconstruction boundaries.
